# Order Form Generator

A Google Apps Script tool for generating monthly order forms based on warehouse stock levels and standardized inventory data.

## 📦 Features

- Generates order forms for each warehouse or truck.
- Pulls on-hand stock data and suggests order quantities.
- Flags low stock levels for reorder.

## 📌 Use Case

Created to support warehouse managers and technicians by simplifying the material ordering process.  
Ensures products are ordered consistently and stockouts are avoided.

## 🚀 How to Use

1. Ensure warehouse stock data is updated in `Clean On-Hand` sheet.
2. Run the `Generate Order Forms` Apps Script function.
3. Review auto-generated forms and submit orders accordingly.
